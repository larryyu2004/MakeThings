# 沿着数值轴建立前缀表

常见的前缀和沿数组位置累积：`prefix[i]` 描述第 `i` 个位置以前的数据。另一个问题是：**已经见过的数值**中，有多少落在 `[L, R]`？此时前缀表的轴是数值范围，而不是输入顺序。

## 明确表的含义

假设数值在 `0..maxValue` 中。令 `prefix[v]` 表示已出现且严格小于 `v` 的元素数量。那么闭区间 `[L, R]` 内的数量就是 `prefix[R + 1] - prefix[L]`。例如已见过 `[1, 3, 2]`：`prefix[1] = 0`、`prefix[3] = 2`、`prefix[4] = 3`，所以 `[2, 3]` 有 `prefix[4] - prefix[2] = 3 - 1 = 2` 个元素。

额外的终点很重要：当 `R == maxValue` 时仍要访问 `R + 1`，因此下标覆盖到 `maxValue + 1` 的表需要 `maxValue + 2` 个槽位。它和按位置求前缀和都使用相减公式，但下标的含义完全不同。

## 一次建立，多次查询

如果查询前，所有历史值已确定，可以先统计每个值的出现次数，再累加。下面的 C++ 代码要求输入值及查询边界都在 `0..maxValue` 内：

```cpp
std::vector<int> prefix(maxValue + 2, 0);
for (int value : seen) ++prefix[value + 1];
for (int v = 1; v <= maxValue + 1; ++v)
    prefix[v] += prefix[v - 1];

auto countInRange = [&](int left, int right) {
    return prefix[right + 1] - prefix[left];
};
```

建表需要 `O(n + maxValue)` 时间、`O(maxValue)` 空间；每次查询为 `O(1)`。数值范围小、同一批数据需要查询多次时，这种方法很合适。负数或极大的数值范围需要基于已知边界设置偏移、离散化，或换一种数据结构。

## 如果数据不断到来？

旧笔记让每次插入都更新该数值以上的所有 `prefix[v]`。查询仍是常数时间，但每次插入变成 `O(maxValue)`。若插入与范围查询频繁交错，可以在数值轴上使用树状数组，让更新和查询都达到 `O(log maxValue)`。选择方案应看操作顺序，而不只看它是否叫“前缀”。
